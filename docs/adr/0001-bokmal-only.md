# 0001. Teach bokmål only

- Status: Accepted
- Date: 2026-11-23

## Context

Norwegian has two written standards, bokmål and nynorsk. The target users are adults moving to Norway for work, starting in Oslo, where bokmål is used in almost all workplaces and public communication.

## Decision

All lessons, exercises and generated content use bokmål. Nynorsk is out of scope.

## Consequences

- Content production and review effort is focused on one standard.
- Learners who need nynorsk (for example in parts of western Norway) are not served.
